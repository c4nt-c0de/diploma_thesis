# Diploma Thesis
Repository containing snippets of code from my diploma thesis used for analyzing local field potential (LFP) recordings and operant behavior in a TgF344-AD rat model of early-stage Alzheimer's disease. This work was possible due to collaboration with the Institute of Physiology of the Czech Academy of Sciences.

Most of it is not well organized, rather it's a loose collection of Python notebooks... In this repository, I'm mostly placing only the parts which may be useful in the future.
