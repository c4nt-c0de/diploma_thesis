I implemented a set of non-parametric cluster based statistical tests based off the paper authored by Maris and Oostenveld (2007). i still have to explore other options for statistical comparison of electrophysiological data, but this approach made the most sense, as you can design them to suit your particular problem. You can choose which points are allowed to form clusters based on what you count as adjacent values (neughboring samples in time or electrodes nearest each other, for example).

The only disadvantage is the computational complexity, which is why I've used cupy library to transfer most of the computationally heavy parts to the GPU. Our dataset was thankfully not large, but it still cut down the total runtime from weeks to days, As with everything, thisncould still probably be sped up by writing more efficient code, but even this version saved me a lot of time.
